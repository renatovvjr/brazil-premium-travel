# Carnaval hero image provenance

Last updated: 2026-11-26 (Australia/Sydney)

## Owner-supplied generated imagery

The project owner supplied the following four source images and stated that they
were generated using ChatGPT for Curated Brazil Travel:

- `sambodromo_hero.png`
- `frevo_hero.png`
- `carnaval_minas_hero.png`
- `camarote_premium_hero.png`

The source files are retained locally in the ignored
`assets/carnaval-originals/` directory. Responsive WebP derivatives are generated
locally by `scripts/process-carnaval-images.mjs` and published from
`public/images/carnaval/`.

These images are illustrative. They must not be presented as documentary
photographs, depictions of contracted venues, or representations of confirmed
hospitality suppliers. The Carnaval carousel provides a translated on-page
disclosure whenever one of these four images is displayed.

This record documents the owner's provenance statement. It does not assert
absolute copyright clearance, legal exclusivity, endorsement, or a supplier
relationship.

## Existing primary hero image

The first carousel slide continues to use the pre-existing primary Carnaval hero
image referenced by `carnavalImageMap.collectionHero`. It was not replaced or
modified as part of this image update.
